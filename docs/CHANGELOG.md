# Changelog

## 0.1.0

- Adoption de la licence Apache-2.0 pour une diffusion large de l'implémentation de référence.
- Structuration des surfaces publiques par catégorie de bâtiment sous `RE2020/BuildingCategory`.
- Déplacement des cas d'exemple sous `Example`.
- Ajout d'un script pour remplir localement le template Excel de validation CSTB/RE2020 pour le cas Maison Pierre.
- Renforcement des workflows de build et de traçabilité pour préparer la publication.
- Ajout d'un gate de conformité composite avec contrôles de traçabilité, d'alignement de valeurs, de provenance et de dérive d'artefacts.
- Ajout d'une couche d'assurance formelle Lean avec théorèmes discrets, ponts `Real` et certificats d'approximation contrôlés.
- Extension des exports et des gardes pour porter et vérifier les clés juridiques fines (`tableId`, `equationId`, `sourceDoc`, `effectiveDate`).
- Ajout d'artefacts de documentation stratégique et de publication (`scorecard`, plans de benchmark, bundle de preuve, roadmap de keying juridique).
- Ajout d'une section d'onboarding dans `README.md` pour installer VS Code, GitHub Copilot, Lean 4 et `lake`.
